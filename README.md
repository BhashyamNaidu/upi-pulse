# UPI Pulse

> **How is India's UPI ecosystem shifting, and do the official sources agree with each other?**

UPI Pulse is a local-first data lakehouse (PySpark + Delta Lake + dbt + Airflow, deployable to
Azure ADLS Gen2 + Databricks) built on public NPCI and RBI payment statistics.

🚧 Work in progress. See [docs/PROGRESS.md](docs/PROGRESS.md) for current status.
